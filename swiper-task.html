// LNN_buildSw4() 中 creative 分支
if (LNN_fx === 'creative') {
  LNN_conf.creativeEffect = {
    prev: {   // 上一张：缩小左移，以左缘为铰点绕 Y 轴内旋 35°，压向"墙"深处
      shadow: true, origin: 'left center',
      translate: ['-42%', 0, -480], rotate: [0, 35, 0],
      scale: 0.8, opacity: 0.9
    },
    next: {   // 下一张：放大右移进场，像从墙上抽出海报推向观众

      scale: 1.08
    }
  };
}

✍️ 向 AI 追问后，用自己的话写：prev / next 的 transform 各控制什么？

prev 控制当前张左边那些"已翻过去的张"在进度 progress = +1 时的形态：translate 决定位移到哪、rotate 决定转多少度、scale 决定缩多小、z 分量决定压多深；next 同理，控制右边待进场的张在 progress = -1 时的形态。翻页过程中 Swiper 按 progress 在 0 与 ±1 之间线性插值，所以海报是"平滑地从墙上转到眼前"，而不是跳变。

答辩抽问 1

transform 里的百分号是相对谁的？相对轮播容器（.swiper）的原点：0% 表示与当前张完全重合，+100% 是往右平移一整个容器宽，-42% 就是往左挪 42% 个容器宽——不是相对 slide 自身。

答辩抽问 2

改一个数值让卡片转 20 度？把 prev 的 rotate 从 [0, 35, 0] 改成 [0, 20, 0]（next 同步改 [0, -20, 0]），海报内旋变缓、墙更"平"一些；若要平面打斜 20° 则用 [0, 0, 20]。

新参数的作用？enabled：zoom 总开关；maxRatio：最大放大倍数；toggle：是否允许双击切换缩放；minRatio：最小缩放倍数（默认 1）。

答辩四连问 4

现场把 delay 改成指定值？如把 autoplay.delay 从 3200 改成 5000：预期每张停留从 3.2 秒变 5 秒、翻页节奏明显变慢，其余行为（无缝循环、手动后不停止）不受影响。
